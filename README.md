# Monty Hall Simulation Probabilities

This example simulates the Monty Hall problem over many trials to demonstrate why switching doors significantly increases the probability of winning the car. It compares the win rates for sticking with the initial choice versus switching after a goat door is revealed, illustrating the counter-intuitive probabilistic advantage of switching.

## Language

`python`

## How to Run

Save the code as `monty_hall_simulation.py`.
Run from your terminal: `python monty_hall_simulation.py`
